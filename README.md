# 내 손안의 택시

고령 학습자를 위한 한국어 카카오T 온라인 학습 모듈. 김영제의 DD3와 제공 교재의 화면을 바탕으로 제작했습니다.

- 컴퓨터로 약 60분 학습, 자신의 스마트폰에서 호출 준비까지 연습
- 로그인 없이 사용, 서버·분석 도구·계정·데이터베이스 없음
- 브라우저에 진도, 스마트폰 연습 체크, 글씨 크기, 최근 자기평가 저장
- 8문항 평가: 제출 후 해설, 다시 배울 단계 안내, 결과 TXT 다운로드 및 인쇄
- 2쪽 PDF 따라하기 안내서와 HTML 대체본
- 실제 택시 호출이나 결제 서비스와 연결되지 않음

## 실행

Node.js가 있는 환경에서 `npm start` 후 http://127.0.0.1:4173 접속. 빌드는 필요 없습니다. `dist/` 전체가 배포 파일입니다.

## GitHub Pages

새 저장소의 main 브랜치에 이 프로젝트를 올리고, 저장소 Settings → Pages → Source를 GitHub Actions로 설정합니다. 포함된 `.github/workflows/pages.yml`이 dist 폴더를 배포합니다. 프로젝트 하위 경로에서도 동작하도록 모든 자원 경로는 상대 경로입니다.

## 설계 및 범위

설계 추적은 `DESIGN.md`에 기록했습니다. 학습 화면에는 구현 용어나 교수설계 이론명을 노출하지 않습니다. 카드 신규 등록·본인인증·직접결제는 DD3 범위에서 제외합니다. 실제 비밀번호를 입력받지 않습니다.

`review/`는 원자료 추출·검수용 로컬 폴더로 Git에 포함하지 않습니다. 원본 DOCX/PDF 자체를 배포하지 않습니다. 화면 중 카드 세부 정보는 가렸습니다.
